# 09. UI/UX

## 1. 원칙

- **세로 모바일 원핸드**: 주요 CTA는 하단 엄지 존
- 카이로소프트식: **사무실 비주얼 + 하단 메뉴 + 팝업 카드**
- 한 화면 한 목적. 대시보드 나열 금지
- 부채는 숫자만이 아니라 **카드**로 읽히게

---

## 2. 정보 구조 (IA)

```
[메인: 사무실 뷰]
 ├─ 하단 탭: 시장 / 프로젝트 / 직원 / 회사 / 메뉴
 ├─ 상단 HUD: 날짜·배속·현금·신뢰·부채Heat
 └─ 오버레이: 이벤트, 결과, 채용, 연구, 부채 상세
```

---

## 3. 화면별 명세

### 3.1 사무실 메인
- 배경: 확장에 따라 방 크기·가구 증가
- 탭하면 직원 말풍선(상태), 시설 정보
- 진행 중 프로젝트는 책상 위 아이콘/게이지
- Heat≥60 이면 서버실에 경고등

### 3.2 상단 HUD
| 요소 | 표기 | 탭 시 |
|------|------|-------|
| 날짜 | 3주차 금 | 캘린더/일시정지 |
| 배속 | ▶ ▶▶ ⏸ | 토글 |
| 현금 | ₩12,400 | 손익 내역 |
| 신뢰 | ★ 42 | 티어 설명 |
| 부채 | 🔥 64 | 부채 패널 |

### 3.3 시장 (수주)
- 세로 카드 리스트
- 카드 앞면: 제목, 예산, 기간, 난이도별, 필요 스택 아이콘
- 상세: 고객 성격, 예상 매칭률(현재 팀 기준)
- CTA: 수락 / 패스

### 3.4 프로젝트
- 진행 중 목록 + 유지보수 목록 분리
- 상세: 진행 바, 모드 토글, 배치 슬롯, 버그, 귀속 부채 카드
- 배치: 직원 칩 탭 → 슬롯 탭 (드래그 옵션)

### 3.5 직원
- 리스트: 얼굴, 사기/스트레스 바, 현재 배치
- 상세: 스탯 레이더(심플), 스택 XP, 특성, 버스팩터 마크
- 채용 버튼 → 후보자 카드

### 3.6 회사
- 시설 업그레이드
- 연구 트리 (Should)
- 회사 가치 / 간단 랭킹
- 손익 주간 리포트

### 3.7 부채 패널 (시그니처 UI)
- 상단: DP, Heat 바, 주간 이자 예상
- 리스트: Debt Card (이름, 귀속, severity)
- 카드 탭 → 상환 방법 + 담당자 배정
- 멜트다운 직전: 화면 가장자리 펄스

### 3.8 이벤트 모달
- 일러스트/아이콘 + 짧은 텍스트
- 선택지 1~2 (위험도 색)
- 결과 토스트

---

## 4. 플로우 (핵심)

```
첫 실행 → 이름 → 강제 의뢰 → 배치 하이라이트
→ 진행 지켜보기 → 완료 팝업 → 책상 유도
→ 시장 자유 → (스피드 첫 사용 시) 부채 튜토리얼
```

---

## 5. 터치 & 접근성

- 타겟 최소 44×44
- 하단 탭 높이 56~64
- 색 + 아이콘 + 텍스트 병행
- 중요 파괴 행동(폐기, 파산 직전 대출)은 확인 1회
- 애니메이션: 완료 팡페어, 이자 틱, 장애 알람 **3종만** 확실히 (잡다한 모션 금지)

---

## 6. 비주얼 톤

- 밝고 약간 카툰스러운 사무실 (다크 UI 기본 금지 — 기존 타이쿤 가독성)
- 부채/장애만 한시적으로 붉은 오버레이
- 폰트: 시스템 가독성 우선, 숫자 테이블러
- (브랜드 확정 전) 가칭 **Dev Tycoon** / **코드마스터 주식회사**
