- [ ] Debt Card 5종

- [ ] 시장 / 프로젝트 / 직원 탭
- [ ] 이벤트 모달 3종 이상
- [ ] 부채 패널
- [ ] 튜토리얼 가드레일 (첫 의뢰)

### 검증
- [ ] 첫 완료 3분 이내 가능한지
