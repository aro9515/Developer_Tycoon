# 01. 게임 기획서

## 1. 한 줄 컨셉

> **혼자 코딩하던 취준생이, 기술부채와 고객 요구 사이에서 회사를 키워 업계 1위가 되는 모바일 2D 경영 시뮬레이션**

카이로소프트식 **짧은 사이클 + 숫자 성장 + 사무실 배치 재미**에, 개발자 업계 특유의 **기술부채 / 야근 / 트렌드 / 버스팩터**를 핵심 재미로 얹는다.

---

## 2. 타깃 & 포지셔닝

| 항목 | 내용 |
|------|------|
| 플랫폼 | 모바일 웹 (세로 우선, 터치 UI) |
| 장르 | 2D 경영 시뮬레이션 / 타이쿤 |
| 플레이 세션 | 3~8분 짧은 루프, 백그라운드 진행 가능 |
| 레퍼런스 | 게임개발부 / 편의점 / 핫스프링스토리 구조 + 실제 개발 현장 풍자 |
| 차별점 | “성장”이 아니라 **부채를 끌어안고 성장**하는 게임 |

---

## 3. 플레이어 판타지

1. **초반**: “내가 짠 코드로 돈 벌었다” (프리랜서 생존)
2. **중반**: “사람을 뽑고 일을 나눠준다” (팀장 역할)
3. **후반**: “회사 기술 방향을 정한다” (CTO 역할)

핵심 감정 곡선: **뿌듯함 → 압박 → 위기 → 리팩토링 카타르시스 → 확장**

---

## 4. 핵심 재미 기둥 (Pillars)

### P1. 배치의 재미
직원을 프로젝트에 올리고, 역할(FE/BE/QA/DevOps)을 맞추는 퍼즐.

### P2. 부채의 긴장감
빠르게 가면 돈이 들어오지만, 기술부채가 **이자처럼 불어나고** 어느 날 장애로 폭발한다.

### P3. 성장의 가시성
사무실이 넓어지고, 책상·서버실·휴게실이 늘어나며 “우리 회사 커졌다”가 눈에 보인다.

### P4. 업계 밈 이벤트
금요일 배포, 요구사항 변경, AI 장애 등 **개발자만 웃을 수 있는 랜덤 이벤트**.

## 6. 진행 아크 (캠페인 톤, 스토리 모드 X)

| 단계 | 칭호 | 목표 감각 | 해금 |
|------|------|-----------|------|
| 0 | 취준생 | 첫 외주 완료 | 기본 IDE |
| 1 | 프리랜서 | 월 수입 안정 | 2번째 프로젝트 슬롯 |
| 2 | 1인 스튜디오 | 첫 직원 채용 | 작은 사무실 |
| 3 | 스타트업 | 동시 3프로젝트 | 회의실 / 코드리뷰 |
| 4 | 성장기 | 기술부채 위기 돌파 | CI/CD, QA 채용 |
| 5 | 중견 | CTO 모드 (직접 코딩 감소) | 연구실, 교육실 |
| 6 | 업계 TOP | 회사 가치 N 달성 | 엔딩 배지 / 뉴게임+ |

※ 스토리 컷신은 MVP 제외. **단계 전환 팝업 + 사무실 비주얼 변화**로만 표현.

---

## 7. 승리 / 패배 / 소프트 페일

### 승리 조건 (MVP)
- 회사 가치 ≥ 목표치 **또는** 업계 랭킹 1위 유지 N주

### 게임 오버
- 자금 < 0 이고 파산 유예 3일 초과
- 신뢰 0 + 진행 중 프로젝트 전멸

### 소프트 페일 (카이로소프트식)
- 직원 대량 퇴사 → 재기 가능하나 랭킹/가치 대폭 하락
- 기술부채 폭발 → “긴급 리팩토링 주간” 강제 이벤트

---

## 8. 아트 / 톤

- **비주얼**: 픽셀 or 심플 2D 아이소메트릭 사무실 (모바일 가독성 우선)
- **톤**: 유머러스한 업계 풍자, 하지만 수치 경영은 진지
- **텍스트**: 짧은 한국어, 밈은 남발하지 않고 이벤트에만

---

## 9. MVP에서 증명할 것

1. “프로젝트 수주 → 배치 → 완료 → 돈/성장” 루프가 **중독적인가**
2. 기술부채가 **전략 선택**으로 느껴지는가 (패널티 숫자 나열이 아닌가)
3. 모바일 세로 UI에서 **한 손 조작**이 되는가

이 세 가지가 Yes면 확장 콘텐츠(해외지사, 상장 등)로 간다.
